# 1. Design Philosophy

The experience should feel like a blend of:

- Apple Store
- Back Market
- Best Buy
- Swappa

Core Principles:

1. Mobile-first
2. Fast and simple
3. Trust-building
4. Easy purchasing
5. Minimal clicks to checkout
6. Localization-first customer experience
7. Plain-language communication
8. Trust through clarity and transparency

---

# 2. Brand Direction

Style:

- Modern

- Trustworthy

# 26. Guiding Principle

When making design decisions:

1. Trust over aesthetics
2. Simplicity over features
3. Mobile over desktop
4. Conversion over decoration
5. Speed over complexity

# 27. Localization Design Requirements

- All customer-facing text must be translatable.
- Design for longer translated text.
- Avoid text embedded in images.
- Icons should support language comprehension.
- Language switcher must be visible on all pages.
- English and Spanish supported for MVP.
- Preserve locale while navigating.
- Preserve locale through checkout.
- Product images should not contain critical translatable text.
- Customer-facing emails should match the customer's selected language.
- Design layouts must accommodate longer Spanish text.

The website should feel like a trustworthy local electronics retailer, not a generic template or flashy startup.
