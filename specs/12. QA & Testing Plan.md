# 1. Purpose

This document defines the quality assurance and testing strategy for the Wireless Connect Online Store.

The goal is to ensure:

- Customers can browse, cart, and checkout successfully
- Admins can manage inventory and orders
- Staff can manage device intake, testing, and IMEI verification
- Warranty records are created and searchable
- Payments are reliable
- Inventory updates correctly
- Private data stays protected
- The site is ready for production launch

---

# 2. Testing Principles

1. Test critical money flows first.
2. Test inventory accuracy carefully.
3. Test admin permissions.
4. Test mobile experience.
5. Test Stripe webhooks.
6. Test RLS/security policies.
7. Do not rely only on manual testing.
8. Every sprint should end with a test pass.

9. Test localization as a first-class feature.
10. Verify English fallback behavior.
11. Verify customer locale persistence.

# 8. Stripe Tests

Use Stripe test mode.

## Successful Payment

Test:

```text
Checkout session completed
→ Webhook received
→ Order marked paid
→ Inventory decremented
→ Confirmation email triggered
→ Localized confirmation email triggered
→ Warranty records created
```

## Failed Payment

Test:

```text
Payment fails
→ Order marked failed
→ Inventory not decremented
```

## Abandoned Checkout

Test:

```text
User leaves Stripe
→ Order remains pending/unpaid
→ Inventory not decremented
```

## Duplicate Webhook

Test:

```text
Same webhook received twice
→ Order not double-processed
→ Inventory decremented only once
```

## Refund

Test:

```text
Refund event received
→ Order payment status updated
→ Inventory not automatically restocked
```
