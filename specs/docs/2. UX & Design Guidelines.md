# 1. Design Philosophy

The experience should feel like a blend of:

- Apple Store
- Back Market
- Best Buy
- Swappa

Core Principles:

1. Mobile-first
2. Fast and simple
3. Trust-building
4. Easy purchasing
5. Minimal clicks to checkout
6. Localization-first customer experience
7. Plain-language communication
8. Trust through clarity and transparency
9. Nationwide credibility — design must convey trustworthiness to customers outside the local market
10. Graceful error handling — custom 404 and 500 pages must never show raw errors or stack traces

---

# 23b. Error Page UX Requirements

## 404 Not Found Page

Must display a custom 404 page — not the framework default.

Required elements:

- Wireless Connect header and footer
- Friendly message (translated):

  ```text
  Page Not Found
  Sorry, we couldn't find that page.
  ```

- CTA button:

  ```text
  Go Back to Shop
  ```

- Must NOT expose any URL path, stack trace, or technical error detail
- Must be accessible and mobile-friendly

---

## 500 / Error Page

Must display a custom error page — not the Next.js default error boundary.

Required elements:

- Wireless Connect header and footer
- Friendly message (translated):

  ```text
  Something went wrong.
  We're looking into it. Please try again.
  ```

- CTA button:

  ```text
  Return to Homepage
  ```

- Must NOT expose any error messages, stack traces, or internal details
- Error details must be logged server-side only (never surfaced to the customer)
- Must be accessible and mobile-friendly

---

## Implementation

- `app/[locale]/not-found.tsx` — custom 404
- `app/[locale]/error.tsx` — custom error boundary
- Both must render with full site layout (header, footer)

# 27. Localization Design Requirements

- All customer-facing text must be translatable.
- Design for longer translated text.
- Avoid text embedded in images.
- Icons should support language comprehension.
- Language switcher must be visible on all pages.
- English and Spanish supported for MVP.
- Preserve locale while navigating.
- Preserve locale through checkout.
- Product images should not contain critical translatable text.
- Customer-facing emails should match the customer's selected language.
- Design layouts must accommodate longer Spanish text.

The website should feel like a trustworthy local electronics retailer, not a generic template or flashy startup.


```text

```

Clean IMEI:

```text
Verified and ready to activate.
```

## Visual Communication

Whenever possible, combine:

- Text
- Icons
- Color

This improves usability for customers with limited English proficiency.

## WhatsApp Support

Customer-facing pages should provide easy access to WhatsApp support when available.

WhatsApp button position:

- **Product page**: Bottom of product details panel, below trust badges
- **Cart page**: Below the order total, above the checkout button
- **Checkout page**: Sticky help button in lower-right corner (does not obscure form fields)
- **Contact page**: Primary contact CTA alongside phone and email

WhatsApp button must:
- Display the translated label ("Need Help? Chat on WhatsApp" / "¿Necesita ayuda?")
- Open WhatsApp in a new tab (not redirect away from checkout flow)
- Only display when WhatsApp is enabled in store settings (`whatsapp_enabled = true`)
- Not interfere with form inputs or primary CTAs on checkout

# 30. Acceptance Criteria

The UX & Design Guidelines are complete when:

1. Mobile-first design is implemented (44px minimum touch targets).
2. All customer-facing text is translatable (no hardcoded strings).
3. Trust bar displays "Ships Anywhere in the U.S." — not "Local Shoreline Store."
4. Product detail pages include breadcrumb navigation with structured data markup.
5. Category/listing pages include breadcrumb navigation.
6. Custom 404 page is implemented — no stack traces or technical details exposed.
7. Custom 500/error page is implemented — no stack traces or technical details exposed.
8. Site footer includes all legal links (Terms, Privacy, Returns, Warranty, Shipping).
9. Site footer includes the CCPA "Do Not Sell My Personal Information" link in English and Spanish.
10. Account area tabs reflect MVP scope: Orders, Warranty Claims, Profile (no Repairs or Trade-Ins).
11. WhatsApp button appears in all required locations and only when enabled in settings.
12. WhatsApp button does not obstruct checkout form inputs.
13. All trust indicators show both local pickup and nationwide shipping when applicable.
14. Lighthouse scores meet targets: Performance 95+, Accessibility 100, Best Practices 100, SEO 100.
15. Language switcher is accessible on all pages, desktop and mobile.
16. All error messages and validation text are localized.
17. Condition grades are visually distinct (color-coded badges).
18. Loading states use skeleton loaders — no blank screens.
19. Cart drawer uses slide-over pattern with sticky checkout button.
20. Network Compatibility tooltip is available on product pages.
