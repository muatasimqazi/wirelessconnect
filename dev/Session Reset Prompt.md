# Session Bootstrap

Read these files in order:

1. spec/AI_CONTEXT.md
2. spec/docs/current_sprint.md
3. spec/docs/open_tasks.md

After reading them:

1. Summarize your understanding of:
   - Product
   - Architecture
   - Current implementation status
   - Outstanding work

2. Identify:
   - Missing context
   - Contradictions
   - Risks

3. Do NOT redesign architecture.
4. Do NOT replace frameworks.
5. Do NOT introduce new dependencies unless explicitly requested.
6. Preserve all existing conventions and contracts.

When proposing code:
- Prefer existing patterns.
- Reuse existing services.
- Reuse existing schemas.
- Reuse existing components.

Before making changes:
- Explain the impacted files.
- Explain the migration path.
- Explain potential regressions.

Wait for further instructions after your analysis.
